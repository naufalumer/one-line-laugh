One funny line for make.fun's "The One-Line Laugh": my smartwatch congratulated me for standing up, which is the only applause I have received all year. A single sentence of 100 characters — an everyday truth with the surprise saved for the end. `main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`; `entry.txt` holds the same line for reading.

## Run it

```sh
python3 main.py
```
